# Web Scraping in R – Tutorial (STAT 260)

An 8-page tutorial I wrote on scraping static and dynamic websites in R using **rvest**, **RSelenium** and **Rcrawler**, for my STAT 260 final project at Simon Fraser University (Spring 2025).

This repo hosts the practice pages used in the tutorial's examples, published with GitHub Pages:

- [webscrapingresources.html](https://cathelyn06.github.io/webscrapingRcath/webscrapingresources.html) – a simple page for reading HTML and extracting text
- [cssselectorsexample.html](https://cathelyn06.github.io/webscrapingRcath/cssselectorsexample.html) – a page for practising CSS selectors (tags, classes and IDs)

**Topics covered:** HTML and CSS basics, CSS selectors, nested elements, extracting text and attributes, scraping tables, and automating a browser for dynamic pages.
